## 第 1 章 Hello World —— 认识一个 C 程序

**源文件：`Hello world.c`**

```c
//頭文件
#include <stdio.h>

//主函數，一個程序只能有一個主函數
int main(void)   // 注意拼寫與引用函數是否存在
               // int 表示整數類型，main 表示主函數，void 表示無參數
{
    // 打印，輸出到屏幕，\n 表示換行
    printf("Day 1 of Learning C: Starting with Hello World\n");  // 注意添加分號

    // 約定 0 返回表示程序正常結束
    return 0;
}
```

### 1.1 这一章学到的东西

| 代码 | 含义 |
| --- | --- |
| `#include <stdio.h>` | 头文件。把"输入输出"这套工具引进来，`printf` 靠它才能用 |
| `int main(void)` | 主函数。**一个程序只能有一个主函数**，程序从它开始执行 |
| `int` | 整数类型 |
| `main` | 主函数的固定名字 |
| `void` | 表示"没有参数"，即不接收外界传进来的数据 |
| `printf("...");` | 打印，把内容输出到屏幕 |
| `\n` | 换行符，打印完换到下一行 |
| `return 0;` | 约定返回 0 表示程序正常结束 |
| `// 注释` | 单行注释，写给程序员看的，电脑不会执行 |
| `/* ... */` | 多行注释（第 3 章用到），跨越多行的说明 |

### 1.2 关键提醒

- **`main` 拼写**：写错成 `mian`、`Main` 都会编译报错。
- **分号**：每条语句结尾必须有 `;`，这是最容易漏的。
- **一个程序只有一个 `main`**：一个项目里如果有两个 `.c` 文件各带一个 `main`，链接时会报错"找到一个或多个多重定义的符号"。

## 第 2 章 圆的面积与周长 —— 变量与 printf 格式符

**源文件：`Circle_calc.c`**

```c
#include <stdio.h>

int main(void)   // int 一個整數，main 為主函數，void 表示無參數
{
    int r;        // int 一個整數，r 為半徑
    float c, s;   // float 一個浮點數，c 為圓周長，s 為圓面積

    r = 5;                      // 半徑為 5
    c = 2 * 3.14159 * r;        // 圓周長公式為 2πr
    s = 3.14159 * r * r;        // 圓面積公式為 πr²

    printf("r=%d,c=%.2f,s=%.2f\n", r, c, s);
    // 輸出半徑、圓周長、圓面積
    // %d 表示整數佔位符
    // %.2f 表示浮點數保留兩位小數
    return 0;
}
```

### 2.1 变量的"先声明，后使用"

C 语言规定：**变量必须先告诉电脑"我要用"，才能用。**

```c
int r;      // 第一步：声明（告诉电脑"我要一个装整数的盒子，叫 r"）
r = 5;      // 第二步：赋值（把 5 装进去）

float c, s; // 同一条语句可以声明多个同类型的变量，用逗号隔开
c = 2 * 3.14159 * r;
s = 3.14159 * r * r;
```

声明与赋值也可以**合并成一步**，这叫"初始化"：

```c
int r = 5;          // 声明的同时赋值（初始化）
float c = 2 * 3.14159 * 5;
```

### 2.2 两种数据类型

| 类型 | 名字 | 能装什么 | 本程序用途 |
| --- | --- | --- | --- |
| `int` | 整型 | 整数（5、12、-3） | 半径 `r` |
| `float` | 单精度浮点型 | 带小数点的数（3.14159） | 周长 `c`、面积 `s` |

> 说明：`float` 是"浮点型"的一种。当前只学 `int` 和 `float` 两种类型。

### 2.3 printf 里的占位符

`printf` 用**占位符**告诉电脑"这里该填什么类型的数据"：

```c
printf("r=%d,c=%.2f,s=%.2f\n", r, c, s);
```

**规则：占位符的数量和顺序，必须与后面的变量一一对应。**

| 占位符 | 含义 | 对应变量 |
| --- | --- | --- |
| `%d` | 整数占位符，填一个 `int` | `r`（值为 5） |
| `%.2f` | 浮点数，保留 2 位小数 | `c`（周长） |
| `%.2f` | 浮点数，保留 2 位小数 | `s`（面积） |

运行结果：

```
r=5,c=31.42,s=78.54
```

### 2.4 为什么 `%d` 和 `%.2f` 不能混用

| 类型 | 该用的占位符 | 用错会怎样 |
| --- | --- | --- |
| `int` | `%d` | 用了 `%f` 会打印出乱七八糟的数 |
| `float` | `%f` / `%.2f` | 用了 `%d` 会打印出乱七八糟的数 |

**记住：占位符要与变量类型配对，这是硬性规则。**

## 第 3 章 比较两个数 —— 容错输入与自定义函数

**源文件：`compare_two_numbers.c`**

```c
/*
 * 程序名：compare_two_numbers.c
 * 功能：从键盘读取两个整数（用英文逗号隔开），
 *       若格式错误或未使用英文逗号，则提示并重新输入，
 *       最后输出两个数中的较大值。
 */

#define _CRT_SECURE_NO_WARNINGS        // 关闭 VS 对 scanf 等函数的安全警告
#include <stdio.h>                    // 提供 printf / fgets / sscanf
#include <string.h>                   // 提供 strchr，用于查找字符

/* 自定义函数：返回两个整数中的较大值 */
int Max(int a, int b)
{
    if (a > b)                        // 若 a 大于 b
        return a;                     // 返回 a
    else                              // 否则
        return b;                     // 返回 b
}

int main()
{
    int x, y;                         // 存放用户输入的两个整数
    char line[100];                   // 字符数组，存放用户整行输入
    int ok = 0;                       // 标记：是否已成功读到两个整数（0=否，1=是）

    printf("Please enter two integers separated by an English comma\n");

    /* 只要还没成功读到两个数，就一直循环 */
    while (!ok)
    {
        printf("> ");                 // 输入提示符，提示用户在此输入

        /* fgets：从键盘(stdin)读取一整行，存入 line
         * sizeof(line) 限制最多读取的字符数，防止缓冲区溢出 */
        fgets(line, sizeof(line), stdin);

        /* strchr：在 line 中查找英文逗号 ','
         * 若返回 NULL，说明没找到英文逗号 */
        if (strchr(line, ',') == NULL)
        {
            printf("Error: no English comma ',' found. Please try again!\n");
            continue;                 // 跳过本次剩余代码，回到循环开头重新输入
        }

        /* sscanf：从字符串 line 中按 "%d,%d" 格式解析两个整数
         * 返回值等于成功读到的数据个数，期望为 2 */
        if (sscanf(line, "%d,%d", &x, &y) == 2)
        {
            ok = 1;                   // 成功读到两个，设标记为 1，跳出循环
        }
        else
        {
            printf("Error: invalid format. Enter two numbers separated by an English comma (e.g. 12,13)!\n");
        }
    }

    printf("The larger value is: %d\n", Max(x, y));   // 调用 Max 并输出结果
    return 0;                         // 程序正常结束
}
```

### 3.1 程序整体结构

整个程序分三块：

1. **开头**：`#define` 和 `#include`（告诉电脑要什么工具）
2. **`Max` 函数**：放在 `main` 前面，自己写的比大小工具
3. **`main` 函数**：程序主体，调用上面的工具

### 3.2 `#define _CRT_SECURE_NO_WARNINGS` 是什么

这是 **Visual Studio 专用的一个开关**，必须放在所有 `#include` 的**最上面**。

**作用**：关闭 VS 对 `scanf`、`fgets` 等函数的安全警告。

**为什么需要它**：VS 认为这些函数"不安全"，会弹警告甚至报错。加上这一行，VS 就不吵了。

> 注意：它不是 C 语言标准的内容，只是 VS 的"方言"。换别的编译器（如 gcc）不需要这行。

### 3.3 两个头文件各管什么

| 头文件 | 提供的工具 | 本程序用途 |
| --- | --- | --- |
| `#include <stdio.h>` | `printf`、`fgets`、`sscanf` | 打印、读整行、从字符串读数据 |
| `#include <string.h>` | `strchr` | 在字符串里查找字符 |

**用到了什么工具，就包含对应的头文件。**

### 3.4 自定义函数 `Max`

```c
int Max(int a, int b)
{
    if (a > b)
        return a;
    else
        return b;
}
```

| 部分 | 含义 |
| --- | --- |
| `int` | 这个函数**返回一个整数** |
| `Max` | 函数名，自己起的 |
| `(int a, int b)` | 接收两个整数，叫 `a` 和 `b`（`a`、`b` 是形参） |
| `return a;` | 把 `a` 的值"带回去"给调用者 |
| `return b;` | 把 `b` 的值"带回去"给调用者 |

**调用方式：**

```c
Max(x, y)        // 把 x、y 的值传进去，函数返回较大的那个
```

**`Max(x, y)` 整个表达式的值，就是返回的那个数。** 所以可以直接放进 `printf`：

```c
printf("The larger value is: %d\n", Max(x, y));
//                                     ↑ 这里就是那个"较大的数"
```

### 3.5 `ok` 标记 + `while (!ok)` 循环

这是本程序最核心的容错思路。

```c
int ok = 0;          // 一开始：还没成功（0 表示"否"）

while (!ok)          // !ok 读作"还没成功吗？"
{
    ...
    if (sscanf(...) == 2)
    {
        ok = 1;      // 读到了，改成 1，循环下次就不进了
    }
}
```

**逻辑链：**

| 步骤 | 代码 | 含义 |
| --- | --- | --- |
| 1 | `int ok = 0;` | 设个标记，初始"没成功" |
| 2 | `while (!ok)` | 没成功就一直循环 |
| 3 | 读输入、判断格式 | 看用户输对了没 |
| 4 | `ok = 1;` | 对了，改标记，下次循环结束 |
| 5 | 循环退出 | 往下执行后面的代码 |

**`!` 是"取反"**：`ok` 是 0（假），`!ok` 就是 1（真），循环继续。

### 3.6 `char line[100]` 是什么

```c
char line[100];   // 字符数组，存放用户整行输入
```

- `char`：字符类型
- `line[100]`：一个能装 100 个字符的盒子（数组）
- 用途：先把用户整行输入接住，再慢慢处理

### 3.7 `fgets`：读一整行

```c
fgets(line, sizeof(line), stdin);
```

| 参数 | 含义 |
| --- | --- |
| `line` | 读到的内容存到这里 |
| `sizeof(line)` | 最多读多少个字符（防止读爆） |
| `stdin` | 从键盘读（`stdin` 是"标准输入"的缩写） |

**为什么要整行读**：如果用 `scanf`，用户输错了程序会卡死。整行读进来再慢慢检查，就不会卡。

### 3.8 `strchr`：在字符串里找字符

```c
strchr(line, ',')     // 在 line 里找英文逗号 ','
```

**它返回的是"位置信息"（地址）。**

| 情况 | 返回值 | `== NULL` 是真是假 |
| --- | --- | --- |
| 找到了逗号 | 一个真实的位置 | 假 |
| 没找到逗号 | `NULL`（表示"没有"） | 真 |

所以：

```c
if (strchr(line, ',') == NULL)   // 没找到逗号吗？
{
    printf("Error: no English comma found.\n");
    continue;                    // 是"没有"→ 报错 → 跳走重来
}
// 走到这里，说明找到了逗号 → 继续往下
```

**`continue` 的含义：跳过本次循环剩下的代码，回到 `while` 开头重新来一次。**

### 3.9 `sscanf`：从字符串里按格式读数据

```c
sscanf(line, "%d,%d", &x, &y)
```

| 部分 | 含义 |
| --- | --- |
| `line` | 从哪读（这里是字符串，不是键盘） |
| `"%d,%d"` | 按"整数,整数"的格式读 |
| `&x, &y` | 读到的内容存到 `x` 和 `y`（`&` 表示"取地址"） |
| 返回值 | **成功读到了几个数据** |

**所以判断 `== 2` 的意思：两个整数都读到了吗？**

```c
if (sscanf(line, "%d,%d", &x, &y) == 2)
{
    ok = 1;      // 读到了 2 个，成功
}
else
{
    printf("Error: invalid format.\n");   // 没读够 2 个，格式错了
}
```

### 3.10 `&` 是什么

```c
&x    // "x 这个盒子的地址"
```

`sscanf` 需要**往盒子里装东西**，所以它要的是"盒子的地址"，不是盒子里的东西。因此必须写 `&x`。

> `&` 当前只需要记住：**`sscanf` 读数据到变量时，变量前面要加 `&`**。

### 4.7 比较与逻辑


| 符号 | 含义 |

```c

{
    ...           // 条件为真时反复执行

```

```c
while (!ok)       // 条件为真就一直循环
{
    ...

```

### 4.10 `continue`

```c
continue;         // 跳过本次循环剩下的代码，直接回到循环开头
```

| 语句 | 作用 |
| --- | --- |
| `continue;` | 跳过本次循环，回到循环开头（循环还继续） |
| `return 0;` | 整个函数结束，程序退出 |

| 函数 | 干什么 | 关键参数 | 返回值 |

## 第 5 章 我的易错点清单

这一章是我本人真实踩过的坑，每次写代码前扫一遍。

1. **`=` 与 `==` 混用**
   - `=` 是赋值（装进去），`==` 是比较（问相等吗）。
   - 判断相等必须用 `==`。

2. **漏写分号 `;`**
   - 每条语句结尾都要有分号。
   - 函数体 `{}` 后面不用分号。

3. **`ok` 标记写反**
   - `int ok = 0;` 是"还没成功"，不能写成 1。
   - 读对了要 `ok = 1;`，不能写成 `ok = 0;`。

4. **`continue` 的走向**
   - `continue` 是"跳走重来"，不是"往下走"。
   - `if (没找到) { ... continue; }` 里，是**没找到才 continue**，找到了是往下走。

5. **`strchr == NULL` 的意思**
   - `== NULL` 是"**没**找到"，不是"找到了"。

6. **`sscanf` 读数据要加 `&`**
   - 写成 `sscanf(line, "%d,%d", x, y)` 会出错，必须是 `&x, &y`。

7. **占位符与类型不配对**
   - `int` 用 `%d`，`float` 用 `%f`。混用会打印乱数。

8. **`%.2f` 里的 `.2` 是"保留 2 位小数"**
   - 不是"除以 2"。

9. **`Max` 函数要写在 `main` 前面**
   - 否则 `main` 里调用时会报"未定义标识符"。

10. **`#define _CRT_SECURE_NO_WARNINGS` 必须放在最顶部**
    - 放在 `#include` 后面不生效。

11. **`char line[100]` 用的是方括号 `[ ]`**
    - 不是 `char line == 100`。`[ ]` 是"开盒子"，`==` 是"比较"。

12. **`sizeof(line)` 是"查一下有多大"，不是"规定大小"**
    - 规定大小的是 `char line[100]` 里的 `[100]`。
